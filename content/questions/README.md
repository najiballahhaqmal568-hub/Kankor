# 📥 پوشه بچ‌های خام سؤالات

فایل خام هر بچ جدید سؤال را همین‌جا بگذار (با نام توصیفی، مثل `batch6_biology.json`) و از ریشه پروژه اجرا کن:

```bash
node scripts/merge-batch.mjs
```

اسکریپت خودش:

1. **فایل‌های جدید یا تغییرکرده** را پیدا می‌کند (هش هر فایل پردازش‌شده در `.merged.json` ثبت می‌شود)
2. شکل خام را تشخیص و به schema اپ **نُرمال** می‌کند (دو شکل شناخته‌شده: canonical و flat/correct_index)
3. نام‌های هم‌معنی را **یکدست** می‌کند (ریاضی→ریاضیات، سخت→دشوار)
4. **اعتبارسنجی سخت‌گیرانه** می‌کند و هر سؤال ردشده را با دلیل گزارش می‌دهد:
   - `correct_index` غیر null و در محدوده گزینه‌ها (یا در شکل canonical: دقیقاً یک `correct: true`)
   - دقیقاً **۴ گزینه**
   - `verified: true` (سؤال تأییدنشده وارد بانک نمی‌شود)
   - explanation ،chapter_ref و توضیح why برای همه گزینه‌ها موجود باشد
5. تکراری‌ها (بر اساس `id`) را رد می‌کند — اجرای دوباره بی‌خطر است
6. سؤالات معتبرِ جدید را در `src/data/bank/questions.json` ادغام می‌کند

بعد از هر ادغام موفق:

- `BANK_VERSION` را در `src/data/bank/index.ts` یک واحد بالا ببر (تا seed در IndexedDB دوباره اجرا شود)
- `npm run test && npm run build` و بعد commit + push — انتشار در GitHub Pages خودکار است

نکته: اگر بچی **اصلاح** شد (تغییر محتوای سؤالِ موجود، نه افزودن سؤال جدید)، ادغام خودکار آن را نمی‌گیرد — تکراری‌ها بر اساس id رد می‌شوند. اصلاح سؤال موجود را مستقیم در `src/data/bank/questions.json` اعمال کن.
