# آمادگی کانکور افغانستان 🎓

اپ آمادگی امتحان کانکور افغانستان — یک **PWA کاملاً آفلاین** به زبان دری (RTL) با دارک‌مود و پالت لاجورد/زعفرانی.

> 🔄 **ادامهٔ پروژه توسط توسعه‌دهنده یا دستیار جدید؟** از [`HANDOFF.md`](HANDOFF.md) شروع کن —
> سند خودکفای انتقال: وضعیت فعلی، مدل داده، جریان کاری محتوا، قواعد غیرقابل‌مذاکره و کارهای باز.

## قابلیت‌ها (فاز ۱ — MVP آفلاین)

- 📚 **بانک سؤالات** — فیلتر بر اساس مضمون، مبحث و سطح سختی + حالت تمرین با بازخورد فوری و توضیح هر گزینه
- 📝 **شبیه‌ساز آزمون** — آزمون کامل (از کل بانک؛ هدف نهایی ۱۶۰ سؤال / ۱۸۰ دقیقه)، مضمونی یا سفارشی، با تایمر دقیق، شبکه ناوبری، پرچم‌گذاری و ادامه آزمون نیمه‌کاره
- 📊 **کارنامه هوشمند** — تحلیل مضمون‌به‌مضمون، ضعیف‌ترین مباحث، توضیح هر ۴ گزینه و پیشنهاد مطالعه گروه‌بندی‌شده
- 🔁 **مرور فاصله‌دار** — الگوریتم SM-2؛ سؤال‌های غلط خودکار وارد صف مرور می‌شوند
- 🌙 دارک‌مود / تم روشن، اندازه فونت قابل تنظیم، اعداد و تاریخ دری
- 📴 **کاملاً آفلاین** — بانک سؤالات همراه اپ، داده‌های کاربر در IndexedDB، قابل نصب روی موبایل

## اجرا

```bash
npm install
npm run dev        # سرور توسعه
npm run build      # بیلد تولید (+ Service Worker)
npm run preview    # پیش‌نمایش بیلد
npm run test       # تست‌های واحد (vitest)
```

## معماری

- **Vite + React + TypeScript**، مسیریابی با HashRouter
- **Dexie (IndexedDB)** برای داده‌های کاربر؛ سؤالات از JSON استاتیک seed می‌شوند
- **vite-plugin-pwa (Workbox)** برای کارکرد آفلاین و نصب
- CSS خالص با توکن‌های طراحی؛ فونت Vazirmatn باندل‌شده لوکال

جزئیات بیشتر در `PROJECT_NOTEBOOK.md`، `ROADMAP.md` و `DECISIONS.md`.

## افزودن سؤال جدید

فایل JSON مربوط به مضمون را در `src/data/bank/` ویرایش کنید (هر سؤال دقیقاً ۴ گزینه با `explanation` و یک `studyHint` دارد)، سپس `BANK_VERSION` را در `src/data/bank/index.ts` یک واحد افزایش دهید تا در اجرای بعدی دوباره seed شود.
